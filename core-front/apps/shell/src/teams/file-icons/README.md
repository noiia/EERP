# Team file icons

Copied unchanged from the Euro-Office document server image
(`web-apps/apps/common/main/resources/img/doc-formats/*.svg`, AGPL-3.0, like the
document server EERP already ships), so the Teams file list shows the same format
icons as the editor. `../FileIcon.tsx` maps a file name's extension to one of them;
add a format by copying its SVG here and adding it to that map.
